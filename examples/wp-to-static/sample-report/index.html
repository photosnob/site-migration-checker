How a result was decided

  • Staging mode requests each old path on the new host. Live mode requests the old URL as published.
  • Redirects are followed one hop at a time. A loop or the hop cap stops the walk. The client does not hide hops.
  • With a redirect map, the expected page is the first matching rule. Without one, the same path on the new host is expected.
  • A single 301 or 308 to that page is the permanent-move shape. 302, 303, and 307 are flagged even if the page is right.
  • Homepage redirects from any other path are soft-404 risks. Protocol and trailing-slash differences are separate from a wrong path.
  • Content is read from the response HTML. JavaScript is not executed. Word count is whitespace-separated visible text, excluding head, script, and style.
  • When a rule names a destination, content is compared to that destination even if the server currently sends people somewhere else.
  • Readiness is BLOCKED on any critical issue, NEEDS REVIEW on high issues, READY WITH NOTES on medium or low issues, and READY otherwise. Info and suggestions do not block.

Issue codes

http_404
critical The probed URL, or the page it redirected to, returned 404.
http_5xx
critical The server returned a 5xx status, so the URL cannot be migrated cleanly.
http_4xx
high The server returned a 4xx status other than 404.
fetch_error
high The URL could not be fetched. Nothing about that URL was verified.
redirect_loop
critical The redirect chain visits the same URL twice.
redirect_homepage
critical A non-home URL redirects to the homepage. Search engines treat that pattern as a soft 404.
redirect_chain
high More than one redirect sits between the old URL and the final page. Collapse it to one hop.
temporary_redirect
high A 302, 303, or 307 is a temporary redirect. A permanent move should be 301 or 308.
too_many_redirects
critical The chain exceeded the hop limit and never settled on a document.
redirect_missing_location
high A redirect status came back without a Location header.
bad_redirect_target
high A Location header used a scheme other than http or https.
not_redirected
high The server returned 200 for the old path instead of redirecting to the mapped page.
wrong_target
high The redirect landed on a different path from the one the map (or the same-path move) expects.
redirect_offsite
high The redirect left the new host.
host_mismatch
high The final host differs from the expected host by a www prefix.
protocol_downgrade
high The final URL is http while the new host is https.
protocol_upgrade
info The final URL is https while the expected URL was http.
trailing_slash_mismatch
low The final path and the expected path differ only by a trailing slash.
query_mismatch
medium The path matches, but the query string does not.
unexpected_status
medium The response status was not a document, a redirect, or an error migcheck classifies.
forced_status_mismatch
medium A redirect rule forces a 4xx, and the server returned something else.
noindex
critical The new page sends noindex, in HTML or in an X-Robots-Tag header.
noindex_kept
info Both the old page and the new page send noindex.
canonical_missing
low The new HTML has no rel=canonical. Google can infer one, but a redesign should set it.
canonical_mismatch
high The canonical URL points at a different host or path than the page itself.
title_missing
high The new page has no title element.
title_changed
medium The title changed beyond a site-name suffix. Severity falls to low when the titles are still close.
meta_description_missing
medium The old page had a meta description and the new page does not.
meta_description_shortened
low The meta description shrank to 60% or less of the old length.
h1_missing
medium The new page has no H1.
h1_changed
low The H1 text changed.
multiple_h1
low The new page has more than one H1.
word_count_drop
medium Visible word count fell by at least the configured threshold. Drops of 50% or more are high.
meta_refresh
medium The page returns 200 and uses a meta refresh. Replace it with a 301.
body_truncated
info The response body was longer than the byte cap, so the word count was not compared.
map_duplicate
low The same source pattern appears twice with the same target and status. First match wins.
map_conflict
high The same source pattern appears twice with a different target or status. First match wins.
map_cycle
high Literal rules send a path back to itself.
map_shadowed
medium An earlier rule already matches every path this rule could match, so this rule never runs.
map_target_404
critical A concrete redirect target returns 404 or 410.
map_target_error
high A concrete redirect target could not be fetched or returned an error other than 404.
map_parse_error
medium A line in the redirect file could not be parsed and was skipped.
map_unsupported
info A rule uses a feature migcheck does not simulate (conditions, mid-path stars, or query matches).
map_temporary
medium A rule uses a temporary status. Permanent moves should be 301 or 308.
map_offsite_target
medium A rule sends the URL to a host other than the new site.
map_targets_homepage
critical A rule sends a non-home path to the homepage.
map_rewrite
info A rule uses status 200, which is an internal rewrite rather than a client redirect.
map_force_flag
info A Netlify or Cloudflare rule uses the force flag. migcheck does not see the file tree.
robots_disallow
critical robots.txt blocks a URL that the migration expects to be reachable.
robots_blocks_all
critical robots.txt disallows the whole site.
robots_missing
medium The new host has no robots.txt. Crawling is allowed, but confirm that was intentional.
